# Providers

Each provider fills the contracts that [runtime components](../runtime-components.md) lists, and has a folder of its own with an index. The notes in that folder name the provider's products and how they fill each role. See [the docs charter](../../README.md) for how a note is written.

## What providers exist

One row per provider, kept by hand: adding a provider's folder here is part of writing it.

| Provider | Explains |
|---|---|
| [Cloudflare](cloudflare/README.md) | The Worker, the Workspace Worker, the Durable Objects, the Computer workspace, Browser Run, the shared Claude container and the deploy stack that fill every contract on Cloudflare |
